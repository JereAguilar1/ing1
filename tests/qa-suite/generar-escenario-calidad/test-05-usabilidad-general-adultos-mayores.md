## Prompt

Quiero un escenario general (no de un sistema concreto) de usabilidad, enfocado en accesibilidad para adultos mayores que usan una app por primera vez.

## Criterios de aceptación esperados

- Se distingue explícitamente que es un escenario general, independiente de un sistema concreto.
- Aun siendo general, las 6 partes se cierran con una tabla completa (no queda como un menú de opciones sin resolver).
- Medida de respuesta cuantificable (tasa de finalización de tarea, tiempo, tasa de error), no solo "fácil de usar".

## Respuesta obtenida

Este es un **escenario general** de usabilidad (independiente de un sistema concreto), enfocado en accesibilidad para adultos mayores que usan una aplicación por primera vez. Sirve como plantilla reutilizable para instanciar luego en un sistema específico.

| Parte | Valor |
|---|---|
| Fuente de estímulo | Un usuario adulto mayor, novato en el uso de aplicaciones digitales, con posibles limitaciones visuales, motrices finas o de experiencia previa con tecnología |
| Estímulo | El usuario intenta aprender y completar una tarea de la aplicación por primera vez, sin capacitación ni asistencia previa |
| Ambiente | Primer uso de la aplicación (onboarding), operación normal, sin ayuda de terceros presente |
| Artefacto | La interfaz de usuario de la aplicación (pantallas, controles, textos, flujos de navegación) |
| Respuesta | La interfaz guía al usuario mediante elementos accesibles (alto contraste, tipografía ampliable, lenguaje simple, ayuda contextual, confirmaciones antes de acciones críticas y posibilidad de deshacer), permitiéndole completar la tarea sin asistencia externa y reduciendo la probabilidad de error |
| Medida de respuesta | Al menos el 80% de los usuarios adultos mayores completa la tarea sin ayuda externa en menos de 3 minutos; tasa de error de usuario ≤ 10%; puntaje de satisfacción SUS ≥ 70 |

**Prosa:** "Cuando un adulto mayor usa la aplicación por primera vez para realizar una tarea, sin capacitación ni asistencia previa, la interfaz debe guiarlo mediante elementos accesibles (alto contraste, texto ampliable, lenguaje simple, ayuda contextual) de modo que al menos el 80% de estos usuarios complete la tarea sin ayuda externa en menos de 3 minutos, con una tasa de error de usuario menor o igual al 10% y un puntaje de satisfacción SUS de al menos 70."
